## 🚀 프로젝트 소개

본 프로젝트는 자격증 기반 통합 시스템으로, MVC 패턴을 적용하여 개발되었습니다. 사용자는 개인 정보 관리, 자격증 조회 및 등록, 채용 공고 검색 등의 기능을 이용할 수 있으며, 관리자는 회원 및 자격증 정보에 대한 CRUD(Create, Read, Update, Delete) 작업을 수행할 수 있습니다. 보안 강화 및 사용자 편의성 증대에 중점을 두었습니다.

## ✨ 주요 기능

### 🧑‍💻 회원 관리
*   **회원가입**: BCrypt를 이용한 안전한 비밀번호 암호화 저장.
*   **로그인/로그아웃**: BCrypt 비밀번호 검증 및 세션 기반 로그인 관리.
*   **마이페이지**: 사용자 정보 조회 및 수정 (비밀번호 변경 포함).
*   **회원 탈퇴**.

### 💼 자격증 관리
*   **자격증 목록 조회**: 전체 자격증 목록 및 사용자가 보유한 자격증 목록 조회.
*   **자격증 검색**: 이름으로 자격증 검색 기능 (Select2 라이브러리 활용).
*   **자격증 추가/수정**: 취득일과 함께 보유 자격증 등록 및 업데이트.

### 🏢 채용 공고 및 학과 정보
*   **채용 공고 검색**: Jsoup 라이브러리를 활용하여 외부 채용 사이트(잡코리아)의 채용 공고를 실시간 스크래핑하여 제공.
*   **학과 관련 정보 조회**: 커리어넷 API 연동을 통해 전공 관련 직업 및 자격 정보 제공.

### ⚙️ 시스템 관리 (관리자 기능)
*   **회원 관리**: 관리자 페이지에서 모든 회원 정보(ID, 이름, 이메일, 학과) 조회 및 수정, 삭제.
*   **자격증 관리**: 관리자 페이지에서 시스템에 등록된 자격증 정보(이름, 직무, 요약, 트렌드)를 추가, 수정, 삭제.

### 🛡️ 보안 및 편의성
*   **비밀번호 암호화**: `jBCrypt` 라이브러리를 이용한 강력한 비밀번호 단방향 암호화.
*   **JDBC 드라이버 메모리 누수 방지**: `ServletContextListener`를 활용하여 웹 애플리케이션 종료 시 JDBC 드라이버 및 관련 스레드 리소스 자동 해제.
*   **중앙 집중식 DB 연결 관리**: `JdbcConnectUtil`을 통한 효율적인 데이터베이스 커넥션 관리.
*   **공통 필터**: 모든 요청/응답에 대한 UTF-8 인코딩 처리 및 로그인 사용자 정보 주입.
*   **커스텀 에러 페이지**: `web.xml` 설정을 통해 404 Not Found 및 모든 종류의 서버 오류(500 Internal Server Error) 발생 시 사용자 친화적인 에러 페이지 제공.

## 🛠️ 기술 스택

*   **백엔드**: Java 17, Servlet, JSP
*   **데이터베이스**: MySQL 8.0
*   **웹 서버**: Apache Tomcat 10.1
*   **라이브러리**:
    *   `jBCrypt` (비밀번호 암호화)
    *   `Jsoup` (웹 크롤링)
    *   `Gson` (JSON 처리)
    *   `Select2` (셀렉트 박스 UI 개선)
    *   `mysql-connector-j` (JDBC 드라이버)
*   **개발 환경**: Eclipse EE

## 🏛️ 프로젝트 구조

프로젝트는 명확한 역할 분담을 위해 MVC 패턴으로 구성되어 있으며, 주요 패키지는 다음과 같습니다.

```
student-erp-project/
├── src/main/java/
│   ├── common/              # 공통 유틸리티 (DB 연결, 필터, 비밀번호 암호화 유틸 등)
│   │   ├── JdbcConnectUtil.java
│   │   ├── MainFilter.java
│   │   ├── PasswordUtil.java
│   │   └── JdbcDriverListener.java
│   ├── controller/          # 사용자 요청 처리 및 응답 (Servlet)
│   │   ├── admin/           # 관리자 기능 컨트롤러
│   │   ├── certificate/     # 자격증 관련 기능 컨트롤러
│   │   ├── member/          # 회원 관련 기능 컨트롤러
│   │   └── HomeController.java
│   ├── dao/                 # 데이터베이스 접근 객체 (DAO)
│   │   ├── admin/           # 관리자 관련 DAO
│   │   ├── certificate/     # 자격증 관련 DAO
│   │   ├── department/      # 학과 관련 DAO
│   │   └── member/          # 회원 관련 DAO
│   ├── dto/                 # 데이터 전송 객체 (DTO)
│   │   ├── admin/
│   │   ├── certificate/
│   │   ├── department/
│   │   └── member/
│   ├── exception/           # 커스텀 예외 클래스
│   └── service/             # 비즈니스 로직 처리 (Service)
│       ├── admin/
│       ├── certificate/
│       ├── department/
│       └── member/

    │   ├── lib/             # 외부 라이브러리 JAR 파일

    │   │   ├── common/
    │   │   ├── main/
    │   │   ├── member/

    ├── js/                  # JavaScript 파일
    └── index.jsp            # 메인 페이지
